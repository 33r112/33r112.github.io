Devlog 01：把网站真正跑起来

2026.08.23
Devlog Astro Web

用于测试个人网站项目日志页面的 Markdown 文件。

这次的目标很简单：先不追求设计，也不考虑复杂功能，只确认整个个人网站的基本结构能够正常工作。

目前网站使用 Astro。我最开始对 Astro 的理解很模糊，只知道它和普通 HTML 网站不太一样。真正开始整理之后才逐渐明白：页面、布局、文章和资源文件可以分开管理，而 Markdown 可以直接作为内容来源。

当前进度

目前已经完成：

  • 创建 Astro 项目
  • 本地运行网站
  • 建立文章目录
  • 测试 .md 文件
  • 设计首页
  • 添加游戏记录页面
  • 添加漫画 / 电影记录
  • 部署到 GitHub Pages

Markdown 测试

下面这段只是为了测试各种排版。

粗体文字可以用于强调重点，斜体文字可以用于比较轻的强调，inline code 则很适合显示文件名，例如 package.json 或 astro.config.mjs。

如果需要引用：

先让网站能用，再慢慢把它变好。

这个原则对我现在来说很有用，因为如果一开始就在字体、颜色、动画和布局上纠结，很容易一直停留在“准备做”的阶段。

页面规划

页面 内容 状态
Home 首页与最近更新 计划中
Games 游戏记录 计划中
Manga 漫画记录 计划中
Devlog 项目开发记录 测试中
About 关于本站 计划中

下一步

下一步准备先做一个最基础的文章列表，让网站可以读取这个目录里的 Markdown 文件，并自动显示标题、日期和简介。

如果这一部分稳定之后，再考虑封面、标签筛选和更复杂的视觉效果。

临时结论

现在最重要的不是把网站一次性做成最终形态，而是保证每加一个功能之后，我自己仍然知道它是干什么的。

这篇日志本身也是测试内容。如果你现在能正常看到：

  • 标题层级
  • 列表
  • 表格
  • 引用
  • 粗体
  • 行内代码
  • 分割线

那说明最基本的 Markdown 渲染已经没有问题。
